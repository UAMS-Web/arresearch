Written against v3.3.0.

This wiki documents the ARResearch child theme: a Genesis child theme, based on StudioPress's Minimum Pro, that runs the ARResearch site. It covers setting the theme up, editing the front page, every widget area, menu, template and setting the theme adds, the problems people run into, and how the theme is developed. The [README](https://github.com/UAMS-Web/arresearch/blob/main/README.txt) keeps the short install steps and the changelog.

**Getting started**

- [Setting up the theme](Setting-up-the-theme.md): install Genesis and the child theme, then assign the menus, widgets and background image.

**Guides**

- [Editing the front page](Editing-the-front-page.md): change the volunteer count, the Home Featured widgets and the Homepage Menu.

**Reference**

- [Theme reference](Theme-reference.md): widget areas, menus, page templates, Customizer settings, Genesis defaults, image sizes, and the scripts and styles the theme loads.

**Troubleshooting**

- [Troubleshooting](Troubleshooting.md): symptoms on the front page, the landing page and theme activation, with their causes and fixes.

**Project**

- [Development](Development.md): the tests and checks, what the download contains, and how this wiki is published.
